# Angry Neighbor (Fabric 1.20.1)
Comandos: /neighbor start easy|normal|hard  (gera a casa na sua frente, chaves e o vizinho) | /neighbor stop
F = pegar item/chave (perto do item). Pegue as 3 chaves para escapar. Se F trocar item de mao, mude "Swap Item with Offhand" em Controles.
Ovo de spawn do vizinho: aba Spawn Eggs (criativo).
Build: GitHub Actions (.github/workflows/build.yml) -> baixe o jar em Actions > Artifacts.
